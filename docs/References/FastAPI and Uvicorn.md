# FastAPI and Uvicorn

The [[Subscription service]] stack. Versions pinned in `requirements.txt`.

| Package | Version | Role |
|---|---|---|
| fastapi | 0.141.1 | Routing / API framework |
| uvicorn[standard] | 0.52.3 | ASGI server |
| jinja2 | 3.1.6 | Templates (landing, panel, admin) |
| httpx | 0.28.1 | Async HTTP client (Steam verify, Discord) |
| python-multipart | 0.0.32 | Form parsing |

## Implementation notes

- The app is created with `docs_url=None, redoc_url=None, openapi_url=None`: no autogenerated docs exposed.
- An `@app.middleware("http")` adds the security headers ([[Security review]]).
- `lifespan` starts the monitor `Manager` and shuts it down cleanly.

> [!note] Behind nginx
> `saas/__main__.py` runs uvicorn with `proxy_headers=True` and `forwarded_allow_ips` to trust the `X-Forwarded-Proto/For` sent by [[nginx and systemd|nginx]]. See [[VPS deployment]].

> [!warning] Single worker
> See [[Architecture]]. Monitor state is in memory; multi-worker duplicates everything.
