Conseguir IP, puerto, Steam ID y player token

Estos cuatro datos salen de "parear el servidor" desde el juego. La forma mas facil es con una extension de Chrome que muestra la notificacion de pareo: no hace falta instalar nada mas ni usar la terminal.

Antes de empezar

  • Usar Google Chrome (o un navegador compatible con sus extensiones).
  • Estar conectado al servidor de Rust del que queres los datos.

Pasos

  1. Instalar la extension. Agrega RustPlus.py Link Companion desde la Chrome Web Store (es la que recomienda la documentacion oficial de la libreria que usa esta app).
  2. Iniciar sesion. Hace click en el icono de la extension: te lleva a la pagina de Facepunch. Inicia sesion con tu cuenta de Steam. Al terminar te redirige a una pagina con tus credenciales.
  3. Dejar la pagina escuchando. En esa misma pagina usa la opcion de escuchar notificaciones ("listen for notifications") y dejala abierta.
  4. Parear desde el juego. Volve a Rust, abri el menu con Esc, entra a Rust+ y elegi Pair with Server.
  5. Leer los datos. En la pagina aparece la notificacion con un bloque de texto. Te interesan cuatro campos:
    • ip va al campo IP del servidor
    • port va al campo Puerto Rust+
    • playerId va al campo Steam ID
    • playerToken va al campo Player token (puede ser negativo, copialo con el signo menos)
  6. Pegar y guardar. Completa los campos en este panel y apreta Guardar. Todavia falta el Entity ID de la alarma: mira el otro boton de ayuda.
Alternativa por terminal (si la extension no te funciona)

Necesitas Node.js instalado. En PowerShell, registrate una sola vez:

npx @liamcottle/rustplus.js fcm-register

Se abre un Chrome para loguearte con Steam. Despues pone la terminal a escuchar:

npx @liamcottle/rustplus.js fcm-listen

Dejala abierta y hace el pareo en el juego igual que arriba: la notificacion con los mismos campos aparece en la terminal.

Ojo: el Puerto Rust+ no es el mismo que el puerto con el que te conectas a jugar. Usa siempre el port que llego en la notificacion. El player token es distinto en cada servidor, y si volves a generar credenciales las anteriores dejan de servir: siempre usa la ultima notificacion.

Conseguir el Entity ID de la alarma

El Entity ID identifica esa Smart Alarm en particular. Se consigue pareando el dispositivo, igual que el servidor pero apuntando a la alarma.

Antes de empezar

  • La Smart Alarm tiene que estar colocada y con corriente conectada.
  • Tenes que estar autorizado en el Tool Cupboard de esa base.
  • Ya tenes que haber hecho el login del otro instructivo (extension o terminal).

Pasos

  1. Dejar el listener escuchando. Abri la pagina de la extension RustPlus.py Link Companion con "listen for notifications" activo (o, si usaste la terminal, corre de nuevo npx @liamcottle/rustplus.js fcm-listen).
  2. Parear la alarma. En el juego, para justo enfrente de la Smart Alarm y mirala. Aparece la opcion Pair sobre el dispositivo: activala.
  3. Leer el dato. Llega una notificacion nueva con el campo entityId. Ese numero va al campo Entity ID de la alarma.
  4. Guardar y probar. Apreta Guardar y despues Iniciar monitor. Si todo esta bien, el log muestra "Conectado a Rust+. Escuchando alarma...".
Truco alternativo: sacar el ID sin parear

Pegale un golpe a la Smart Alarm en el juego, abri la consola con F1 y escribi combatlog. El ID de la entidad aparece en la lista como objetivo del golpe. Metodo documentado por la libreria oficial; util si el listener no te llega.

Si el log dice "not_found"

Significa que el servidor conecta pero esa alarma ya no existe con ese ID. Pasa despues de un wipe o si la alarma fue destruida. Solucion: repeti estos pasos y actualiza el Entity ID. Si tambien cambio el servidor, rehace el otro instructivo completo.

Ojo: el Entity ID cambia con cada wipe. Si tenes varias alarmas, pareas una por vez y anotas cual es cual: la notificacion llega con el nombre que le pusiste al dispositivo.
