# skills/

Copia de las skills de diseño y animación de **Emil Kowalski** — [github.com/emilkowalski/skills](https://github.com/emilkowalski/skills).

Instaladas a nivel global en `~/.claude/skills/` (disponibles en todas las sesiones de Claude Code) y copiadas acá para que viajen con el repo.

## Instalar / actualizar

```bash
npx skills@latest add emilkowalski/skills
```

## Qué hay

| Skill | Para qué | Aplica a RustyAlarm |
|---|---|---|
| `emil-design-eng` | Pulido de UI, decisiones de animación, detalles | Sí (panel, landing) |
| `apple-design` | Movimiento fluido, gestos, spring, tipografía | Sí |
| `animate` | Construye una animación de cero (curva, duración, entrada/salida) | Sí |
| `find-animation-opportunities` | Encuentra dónde falta movimiento (y dónde no) | Sí |
| `improve-animations` | Audita todas las animaciones y da plan priorizado | Sí |
| `review-animations` | Revisión estricta de una animación puntual | Sí |
| `animation-vocabulary` | Da el nombre exacto de un efecto | Sí |
| `ask-sonner` | Guía de Sonner (toast de React) | Solo si se migra a React |
| `pick-ui-library` | Elige librería frontend confiable | Solo si se migra a React |
| `prototype` | Genera varias versiones de una UI para comparar | Parcial |

Doc en el vault: `docs/Referencias/Skills de diseño y animación.md`.
